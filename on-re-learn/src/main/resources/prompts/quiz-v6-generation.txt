JSON만 출력해서 퀴즈를 생성해라.
각 문항은 질문과 보기만 보고 풀 수 있는 개념 문제다. 개념 간 차이, 원리의 적용, 상황에 따른 판단을 묻는다.
빈칸 채우기, 문장 암기, 페이지나 원문 위치 맞히기는 출제하지 않는다.
질문에 풀이에 필요한 조건을 쓰고 정답이나 인용문을 그대로 드러내지 않는다.
문항마다 evidence.source는 pdf로 고정하고,
evidence.page는 실제 PDF 페이지 번호, evidence.quote는 그 페이지에서 복사한 12자 이상의 구절을 사용한다.
객관식과 단답형 정답은 인용한 문단에 등장하는 핵심 용어로 고른다.
객관식 오답은 PDF에 등장하며 정답과 같은 범주의 개념을 고른다. 정답은 하나만 성립해야 한다.
OX 문장은 PDF의 설명으로 참 또는 거짓이 명확히 결정되게 작성한다.
메모 연결 목록은 주제 선택에만 사용하며 지정된 상한을 지킨다.

출제 방식 예시. 아래 문항은 형식 설명용이며 실제 출제에는 제공된 PDF의 개념과 근거만 사용한다.
- 객관식: 두 사람이 메시지 변조를 확인하고 송신자를 인증하려 한다. 두 사람만 공유하는 비밀키가 있고 공개키는 준비하지 않았다. 어떤 방법이 조건에 맞는가? 보기 예시는 메시지 인증 코드, 디지털 서명, 단순 해시, 암호화다. 정답은 메시지 인증 코드다.
- OX: 메시지와 해시값을 함께 받은 수신자는 해시값이 일치한다는 사실만으로 송신자의 신원을 확인할 수 있다. 정답은 X다.
- 단답형: 서명자는 개인키로 서명하고 수신자는 공개키로 검증한다. 이 방식을 무엇이라 하는가? 정답은 디지털 서명이다.

정답 형식:
- mcq: { "correctIndex": number }
- tf: { "correct": true|false }
- short: { "accepted": string[] }

선택지 형식:
- mcq: 보기 4개(string[])
- tf: ["O","X"]
- short: null

JSON 스키마:
{
  "title": string,
  "items": [
    {
      "type": "mcq"|"tf"|"short",
      "question": string,
      "choices": string[] | null,
      "answerKey": object,
      "explanation": string,
      "topic": string,
      "points": number,
      "evidence": { "source": "pdf", "page": number, "quote": string },
      "signalHits": string[]
    }
  ]
}

문항 수:
- mcq %s
- tf %s
- short %s
